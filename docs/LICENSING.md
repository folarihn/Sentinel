# Licensing and bundled asset review

The owner approved MIT licensing on November 5, 2026. LICENSE contains the complete MIT text with Copyright (c) 2026 folarihn. pyproject.toml declares that license file. Repository ownership and package authorship identify folarihn.

The runtime package declares no third-party dependencies and includes Sentinel Python and web source only. No third-party JavaScript library, image pack, icon pack, font file or vendored dependency is bundled. CSS names IBM Plex and system fallback fonts but does not download or redistribute font files. Icons are text/CSS. Release screenshots are genuine captures of Sentinel's own interface; the demo is assembled from those captures and a real local runtime recording, with no third-party audio or stock assets.

Build/test tools and Hermes are separately installed software, not relicensed or bundled with Sentinel. Their own licenses continue to apply. The MIT grant applies only to material the owner can license; it does not purport to change third-party rights. This review is scoped to tracked files and the built wheel, not arbitrary files in the developer environment.
